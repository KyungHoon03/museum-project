# 실제 공간 고증 점검표

박물관 모델이 실제 전시 공간처럼 보이는지 확인하는 점검표입니다. 작업할 때마다 이 표를 갱신합니다.
상태: ✅ 확인 완료 · 🔧 수정함(확인 필요) · ⚠️ 남은 문제 · ➖ 해당 없음

- 마지막 점검: 2026-11-12 (Claude, 로컬 브라우저 1인칭 화면과 자동 점검 스크립트)
- 전시 컨셉: **국궁 — 활을 만들고, 쏘고, 겨루는 사람들** (모든 예시 3D·사진 통일)
- 예시 전시물 생성: `python tools/generate_exhibits.py` → `assets/exhibits/*.obj`(3D 14종), `assets/panels/*.svg`(패널)

## 1. 발견한 고증 문제와 처리

| # | 문제 | 원인 | 처리 | 상태 |
|---|---|---|---|---|
| 1 | 유리 진열장 사진이 유리 **바깥**(관람객 쪽)에 떠 있음 | 사진을 진열장 깊이+1.5cm(유리 앞)에 붙임 | 진열장 뒤판 앞면(+0.4cm)에 붙임. 선반·유물·유리가 사진 앞에 옴 | ✅ |
| 2 | 기획전시실 매입 유리 전시부 사진이 유리 앞에 붙음 | 유리 위치 기준 액자 사용 | 매입부 뒤판 실내 쪽 면에 붙임(`recess-display`) | ✅ |
| 3 | 로비 부조 전시부 사진이 앞 목재 테두리보다 7cm 앞에 뜸 | 깊이+7cm로 계산 | 부조 뒤판은 체험마루 서벽 안에 묻혀 있어, 실제 보이는 벽면(+0.4cm)에 붙임. 받침 깊이도 보이는 면 기준으로 다시 계산 | ✅ |
| 4 | 벽걸이 액자 사진이 액자 테보다 앞에 뜸 | 벽에서 5cm(테 앞면 4.3cm보다 앞) | 테 안쪽 깊이(2cm)에 끼움. 자동 검사로 사진 뒤 벽까지 거리 2.0~2.2cm 확인 | ✅ |
| 5 | 로비 남측 긴 매입부 액자가 뒤판에서 4cm 떠 있음 | 액자 기준선 11cm | 뒤판 면(7cm)에 맞춤 | ✅ |
| 6 | 3D 유물이 받침면 위에 **떠 있거나 파묻힘** | 모델 높이를 무시하고 `크기/2` 고정값으로 올림 | 회전 후 최저점을 받침면 높이에 맞춤 | ✅ |
| 7 | 3D 유물이 진열장·유리를 뚫고 나감 | 크기 제한 없음 | 받침면(진열장 안쪽, 유리 덮개 아래) 크기로 자동 축소, 이동도 안쪽으로 제한 | ✅ |
| 8 | 테이블 유물이 가운데 매단 가림막과 겹침 | 테이블 중심선에 배치 | 가림막 양쪽(주 전시실 쪽·복도 쪽)을 별도 받침면으로 나눔 | ✅ |
| 9 | 유리장 안 유물이 유리 **앞에** 그려짐(유리에 안 비침) | 유리를 먼저 그리고 유물을 나중에 그림 | 불투명 → 유물 → 사진 → 유리(먼 것부터) 순서 | ✅ |
| 10 | 사진만 조명을 안 받아 붙여 넣은 듯 보임 | 셰이더에서 사진 색을 그대로 출력 | 벽과 같은 빛 계산으로 약한 음영 | ✅ |
| 10-1 | 일부 사진이 **좌우로 뒤집혀** 보임(로비 연표, 기증전시실 진열장) | 벽 데이터의 a→b 방향을 그대로 사진 왼쪽→오른쪽으로 씀. 영상실 2번은 `flipX`로 손보정돼 있었음 | 관람객이 보는 방향 기준으로 자동 정렬, `flipX` 보정 제거 | ✅ |
| 11 | 3D 유물이 한 가지 색 | 정점 색 미지원 | OBJ 정점 색(`v x y z r g b`) 지원, 뿔·대나무·옻칠·금속 색 구분 | ✅ |
| 12 | 실제 크기 무시(모든 모델을 0.7m로 맞춤) | 정규화 후 고정 배율 | 단위 추정(m/cm/mm) 후 실제 크기, 공간보다 크면 축소하고 패널에 "줄여 놓음" 표시 | ✅ |
| 13 | 평면도 위치 점이 화면에서 어긋남 | 투영식 `vp[12]` 오타(`vp[12+i]`) | 수정 | ✅ |
| 14 | 로비 중앙 대형 각궁이 활 모양 천장 장식(2.38m)에 닿음 | 전시대 높이 한도 2.6m | 로비는 2.33m, 그 밖은 보 아래 2.38m로 제한 | ✅ |
| 15 | 빈 진열장·전시대·테이블이 많음 | 업로드 자리가 18곳뿐 | 물건을 올릴 수 있는 모든 면을 자리로 등록(아래 2장). 3m 넘는 진열장·테이블은 좌·우, 대형 전시대는 여러 자리로 나눠 3D 47 + 사진 22 = 69자리 | ✅ |
| 16 | 예시 사진·모델의 주제가 제각각(올림픽 선수 사진 등) | 임시 자료 | 국궁 컨셉으로 3D 14종·패널 22장 새로 제작. 기존 예시 파일은 `assets/examples/`에 그대로 둠 | ✅ |

## 7. 남은 문제 / 다음 단계

- ⚠️ 과녁 판의 무늬·치수는 실물 사진 대조 없이 단순화했습니다. 실측·사진 자료가 있으면 맞춰야 합니다.
- ⚠️ 기증전시실은 원래 팀이 업로드 대상에서 일부러 뺀 공간이었습니다. 이번에 "빠짐없이" 지시에 따라 자리를 만들었으니 팀원과 확인이 필요합니다.
- ⚠️ **건물 방위 미확인**: 평면도 위쪽을 북쪽으로 계산했습니다. 실제 건물 방향을 알면 조명 패널의 `북쪽 보정`에 각도를 넣어야 햇빛 방향이 맞습니다.
- ⚠️ 실내 조명은 접지 그림자로 대신합니다(햇빛만 실제 그림자 지도). 유물이 옆 벽에 드리우는 그림자는 없습니다.
- ⚠️ 전시 패널(SVG) 디자인은 이번에 손대지 않았습니다. 실제 박물관 그래픽 수준으로 다듬으려면 디자인 작업이 따로 필요합니다.
- ⚠️ 실물 사진·3D 스캔 자료로 바꾸려면 이용 허락(공공누리 등)을 확인한 자료가 필요합니다. 팀과 출처를 정해야 합니다.
- ⚠️ 하루 재생은 시간 계산 함수로만 검증했습니다(시험 중 브라우저 창이 숨겨져 화면 갱신이 멈춤).
- ⚠️ 창·유리문으로 들어오는 햇빛(실내 채광)은 넣지 않았습니다. 박물관은 보통 자연광을 막는다고 보고 단순화했습니다.
- ⚠️ 평면도에 사진 썸네일·번호 점·조명 점이 함께 떠서 복잡합니다. `평면도 표시`를 끄면 조명 점은 숨길 수 있습니다.
